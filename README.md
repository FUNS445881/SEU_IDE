# SEU_IDE

计算机综合设计要求之IDE实现

语言为Python

拟高光支持语言：MiniC

前端使用的pyqt6，也就是pyside

编译器和汇编器由同学负责，core下面两个exe就是。

lex github地址：https://github.com/AqiuNoCold/seulex

yacc github地址：https://github.com/julymiaw/seuyacc

汇编器github地址：https://github.com/Niflheim-witch/python_minisy_asm

启动方式：

1. git init

2. git clone https://github.com/FUNS445881/SEU_IDE/tree/main/my_ide.git

3. 在根目录下激活虚拟环境（python -m venv venv; ./venv/Scripts/Activate.ps1）

4. pip install -r requirements.txt

5. python -m my_ide.main
